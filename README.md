# Planner

캘린더 · 할 일 · 주간계획을 한 화면에서 쓰는 개인용 플래너.
브라우저만 있으면 되고 서버가 필요 없습니다.

## 쓰는 법

`index.html`을 브라우저로 열면 끝입니다.
GitHub Pages를 켜두면 폰에서도 주소로 바로 접속됩니다.

## 기능

- **일정** — 일 / 주 / 월 보기, 드래그로 이동·시간 조절, 여러 날 일정, 반복(매일·매주 요일·매월·매년)
- **할 일** — 곧 / 나중에 / 예정 / 지난, 하위 항목, 목록·보드 보기
- **계획** — 일정과 분리된 초안 레이어. 확정하면 일정으로 넘어감. 주간 템플릿 저장·불러오기
- **블록** — 일정 안에 할 일을 담는 묶음
- **구독** — 대한민국 공휴일(대체공휴일 자동 계산), 음력, 24절기. 천문 계산이라 연도 제한 없음
- **알림** — 항목당 여러 개, 브라우저 알림 + 앱 내 토스트 (탭이 열려 있어야 동작)
- **테마** — 라이트 / 다크 / 시스템, 색 테마 편집·복제
- 검색(`/`, `Cmd/Ctrl+K`), 되돌리기(`Ctrl+Z`), JSON 내보내기·가져오기

## 저장

모든 데이터는 브라우저 `localStorage`에 저장됩니다.

- **브라우저 데이터를 지우면 함께 사라집니다.** 설정 → 데이터 → 내보내기로 가끔 백업하세요.
- 저장이 실패하면 화면 아래에 빨간 막대로 알려줍니다.
- 기기 간 동기화는 아직 없습니다.
